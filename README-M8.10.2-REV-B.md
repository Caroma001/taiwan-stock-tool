# twstock M8.10.2 Rev.B — Bruce 自動觀察池

本修訂版維持 UI 版本 M8.10.2，新增：

- 每日更新完成後，Bruce 精選中「推薦買進 / 分批布局」自動加入觀察池。
- 觀察池最多 20 檔，達上限停止新增。
- 已存在的觀察股、實際持股、測試持股不重複加入。
- 使用者主動取消觀察的股票不會被隔日自動加回。
- 自動保存加入當日收盤價與資料日期作為觀察基準。
- 投資組合顯示觀察編號、目前報酬、觀察交易日、10 日與 20 日報酬。
- 摘要顯示目前獲利 / 未獲利檔數，以及已滿 10 / 20 交易日的檔數。
- 提供「同步推薦到觀察池」按鈕，可在每日更新之外立即測試同步邏輯。

## 觀察池規則

1. 上限 20 檔。
2. 只接受 Bruce 精選建議為「推薦買進」或「分批布局」。
3. 不重複加入相同股票。
4. 實際持股與測試持股不再加入觀察池。
5. 取消觀察視為使用者明確拒絕，系統不自動加回。
6. 10 / 20 日績效以加入日起的交易日計算。
