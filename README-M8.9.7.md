# twstock-M8.9.7 — Ownership Data Validation & TDCC Fix

M8.9.7 修正 M8.9.6 股權分散資料中「大戶 0% / 散戶 199%」的級距解析問題。

## 修正重點

- 正確解析 TDCC / FinMind 的持股級距（含數字級距代碼 1–15 與文字級距）。
- 400,001 股以上歸為大戶區；1,000,001 股以上另標為超級大戶。
- 專案「散戶比例」定義為非大戶代理值 = 100% - 大戶比例。
- 忽略「差異數調整 / 合計」列，不把合計 100% 再加一次。
- 檢查原始級距比例合計必須接近 100%。
- 大戶 + 散戶必須等於 100%（容許 0.2% 浮點誤差）。
- 舊版不合理的 0/199 資料在 migration 19 先標記無效，重新同步後再恢復顯示。
- Bruce 精選新增「完整度」欄位，異常資料不參與股權分散覆蓋率。

## 升級後第一次操作

1. `npm install`
2. `npm run verify`
3. `npm run dev`
4. 進入 `/smart-selection`
5. 按「補齊前20檔籌碼資料」重新取得 TDCC 股權分散資料。

舊的不合理股權比例不會被沿用。
