# M8.10.6.2 — Market Universe & Failure Classification Hotfix

本版只處理「每日一鍵更新」的市場資料效率與錯誤分類，不修改 Winner25、法人潛伏或潛伏雷達評分公式。

## 主要修正

1. **普通股 Market Universe**
   - 每日市場更新只對一般四碼上市櫃普通股建立待更新工作。
   - ETF、ETN、權證與明確非普通股商品在任務建立時直接標記為 `skipped`。
   - 略過項目仍保留在總數與診斷統計中，因此使用者可以看到「成功／略過／失敗」的完整分母。

2. **真正失敗 vs 不適用**
   - 明確無行情、查無資料、無效股票代號改列「略過／不適用」。
   - API 額度、網路逾時、Turso/SQL 等仍保留為真正需要處理的錯誤。

3. **FinMind 額度冷卻**
   - 429/402/Quota 類錯誤不再於幾秒內連續重試四次。
   - 額度限制採 60 分鐘冷卻；網路／逾時採 5 分鐘冷卻。
   - 一旦單一批次偵測到額度限制，立即停止該批後續 API 呼叫，剩餘股票保持待處理。

4. **診斷視窗**
   - 新增「額度冷卻」數量。
   - 冷卻中的項目會顯示為「額度／網路冷卻」，不誤標成永久失敗。

## 同日升級注意

若 M8.10.6.1 已經在今天建立或完成舊任務，M8.10.6.2 不會偷偷刪除原任務。要立即套用新的 Market Universe，請在「進階／維護操作」按一次 **重建今日任務**。之後的新每日任務會自動使用 M8.10.6.2 規則。
