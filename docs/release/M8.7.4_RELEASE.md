# M8.7.4 Release — Responsive UI Engine

## Purpose

修正 M8.7.3 僅調整一般字體、但主導覽與熱門股表格仍使用固定像素字級的問題。

## Changes

- 導覽列加入響應式 class，移除固定字級造成的縮放失效。
- 全站資料表與表格內小字統一受字體設定控制。
- 新增卡片尺寸與按鈕／點擊區尺寸。
- 字體預設改為「中」，提升桌機與 iPad 可讀性。
- 保留五段字體與三段表格密度。
- 不修改 Turso schema、AI 邏輯、更新流程或 Vercel 設定。

## Verification

1. `npm install`
2. `npm run verify`
3. `npm run dev`
4. 檢查 `/daily-lab` 主導覽與熱門股候選池。
5. 切換 XS / M / XL，確認字體與列高立即變化。
