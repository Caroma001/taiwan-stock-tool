# M8.7.3 Release — Display Manager

## Purpose
Improve display controls across desktop, iPad, and smaller screens without changing stock analysis logic or database schema.

## Features
- Header-level `Aa 顯示設定` entry.
- Five font scales: 90%, 100%, 110%, 120%, 135%.
- Three table densities: compact, normal, comfortable.
- Immediate preview and browser persistence.
- Reset-to-default control.
- Accessible modal close behavior and visible keyboard focus.

## Database
No migration.

## Deployment
Manual production deployment through `npm run deploy` after `npm run verify` passes.

## Rollback
Rollback target: M8.7.2.
