# M7.8.5 Release

## Production Health Gate stabilization

M7.8.5 fixes the final M7.8.4 cloud-gate defect:

```text
curl: (3) URL rejected: No host part in the URL
```

The cause was GitHub suppressing a cross-job output because its value matched a
repository secret. The Health Gate therefore received an empty URL.

## Changes

- Removed the `production_url` job output.
- Removed cross-job URL propagation.
- `wait-for-vercel` reads `TWSTOCK_PRODUCTION_URL` directly from Repository Secrets.
- `production-health-gate` independently reads the same secret.
- Added URL validation inside both cloud jobs.
- Increased Vercel propagation wait from 30 to 45 seconds.
- Increased Health/Ready retries from 8 to 10.
- Kept Vercel Git Integration as the only production deployment mechanism.
- No product features or database architecture changes.

## Required GitHub Repository Secret

```text
TWSTOCK_PRODUCTION_URL=https://taiwan-stock-tool-sable.vercel.app
```

Do not add a trailing slash.
