# M7.8.2 — Runtime Convergence

## Goal

Separate local development, CI validation, and production runtime so each environment checks only what it owns.

## Commands

```bash
npm run doctor
npm run check
npm run check:prod
```

## Changes

- Local Doctor alone reads `.env.local`.
- GitHub CI no longer requires local or production secrets.
- CI uses clearly marked compile-only placeholders and never prints real credentials.
- Vercel Production remains the sole owner of real Turso, login, session, admin, cron, and monitoring variables.
- Direct source deployment avoids `vercel pull`, prebuilt output, and `.vercel/project.json` coupling.
- Health and readiness gates run after every successful production deployment.
