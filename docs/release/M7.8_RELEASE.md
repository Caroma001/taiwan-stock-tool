# M7.8 Release — Converged Cloud Runtime

## Goal
M7.8 removes duplicated release-era checks and establishes one canonical path: `npm run check`.

## Acceptance
- One local/CI check command
- GitHub push deploys Vercel Production
- Turso is the production database
- Daily Cron and cloud continuation do not depend on a Mac
- Login, PWA, health and readiness routes remain available on mobile
- Package version is the single version source

## Standard flow
```bash
npm install
cp ../twstock-M7.7.5/.env.local ./.env.local
npm run check
git push origin main
```
