# M7.8.1 Release

## Purpose

Permanent runtime and test architecture cleanup. This release removes version-coupled M61/M62/M69/M74 build and test references from the active workflow.

## Changes

- Renamed runtime source folders to capability-based names.
- Replaced `.m69-runtime` and `.m74-test` with `.runtime/pipeline` and `.runtime/algorithm-test`.
- Replaced version-coupled test configuration references with permanent `tsconfig.pipeline-runtime.json` and `tsconfig.algorithm-test.json`.
- Updated pipeline CLI and all imports to permanent paths.
- `npm run check` remains the single pre-push validation command.

## Standard validation

```bash
npm install
cp ../twstock-M7.8/.env.local ./.env.local
npm run check
```
