# M8.10.20 — High Efficiency Bulk Daily Snapshot Engine

## Objective

Replace symbol-by-symbol upstream downloads with one trading-date snapshot, while preserving the existing Active Job Source of Truth and resumable Queue.

## Daily flow

1. Resolve the effective Taiwan trading date.
2. Acquire a single-date Bulk Snapshot lease.
3. Fetch TWSE + TPEx daily prices and institutional flow in market-wide requests.
4. Fall back to FinMind bulk only when the official bulk path fails.
5. Bulk upsert `daily_prices`, `foreign_investor_daily`, `institutional_holding_daily`, and checkpoints.
6. Rebuild market-wide foreign-accumulation scores in ~12 chunked range reads instead of thousands of per-symbol history reads.
7. Run all 2,143-symbol indicator/decision analysis locally from Turso with **zero symbol-level upstream calls**.
8. Reuse the same institutional snapshot for Winner25 / institutional-stealth candidate postprocessing; only candidate-only special holding/distribution data can be supplemented.
9. Development Center polls one Active Pointer summary every 15 seconds; it never scans the queue just to draw progress.

## Idempotency / quota protection

`daily_bulk_snapshot_runs` is keyed by trading date and protected by a four-minute lease. Concurrent Vercel Queue continuations cannot refetch the same market date. A completed snapshot is reused on every subsequent continuation and page refresh.

## Telemetry

The UI and Active Job Diagnostics expose:

- Bulk status
- price/institutional source
- price rows
- institutional rows
- external request count
- official request count
- FinMind request count
- fallback/error note

This makes it immediately visible whether a failure is an upstream API problem, a Turso problem, or only the local analysis stage.
