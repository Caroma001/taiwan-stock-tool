# twstock-M8.1 共用環境變數

所有版本一律使用這一份檔案：

```text
~/Projects/GN.data/.env.local
```

專案內不建立 `GN.data` 資料夾，也不複製環境變數。

每個版本的專案根目錄只建立一個符號連結：

```text
twstock-M8.1/.env.local -> ../GN.data/.env.local
```

## 第一次設定

確認共用檔已存在：

```bash
ls -la ~/Projects/GN.data/.env.local
```

進入專案：

```bash
cd ~/Projects/twstock-M8.1
```

建立引用：

```bash
node scripts/link-shared-env.mjs
```

檢查：

```bash
node scripts/check-shared-env.mjs
```

或：

```bash
ls -la .env.local
```

正確結果：

```text
.env.local -> ../GN.data/.env.local
```

## 未來每個版本

例如建立 `twstock-M8.3` 後：

```bash
cd ~/Projects/twstock-M8.3
node scripts/link-shared-env.mjs
```

不需再複製 `.env.local`。

## 共用檔應包含

```env
TURSO_DATABASE_URL=
TURSO_AUTH_TOKEN=

```

產生 Session Secret：

```bash
openssl rand -base64 48
```

## Vercel

Vercel 無法讀取 Mac 的 `~/Projects/GN.data/.env.local`。

正式部署時仍需把同樣的變數加入 Vercel Environment Variables。
