# twstock M7.8 Start Here

## First local setup

```bash
npm install
cp ../twstock-M7.7.5/.env.local ./.env.local
npm run check
```

`npm run check` is the only local release gate. It validates environment, PWA, GitHub/Vercel/Turso cloud capabilities, TypeScript, algorithms, pipeline compilation and production build.

## First Git setup

```bash
git init
git branch -M main
git remote add origin https://github.com/Caroma001/taiwan-stock-tool.git
git check-ignore -v .env.local
git add .
git commit -m "Release twstock M7.8.1"
git push -u origin main
```

## GitHub Actions secrets

Set: `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`, `TWSTOCK_PRODUCTION_URL`, `MONITORING_SECRET`, `CLOUD_ADMIN_SECRET`.

Set repository variable `ENABLE_AUTO_ROLLBACK=true` only after the first healthy deployment.

## Vercel Production environment variables

Set: `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `FINMIND_API_TOKEN`, `APP_ACCESS_PASSWORD`, `AUTH_SESSION_SECRET`, `CLOUD_ADMIN_SECRET`, `CRON_SECRET`, `MONITORING_SECRET`.

## Mobile

Open the HTTPS production URL in Safari, sign in, then use Share → Add to Home Screen. The start page is `/daily-lab`; cloud health is available at `/cloud`.

## M7.8 in-place patch: cloud scheduler capability

`npm run check` treats daily cloud execution as two cooperating capabilities:

- Vercel Cron starts `/api/cron/daily`.
- GitHub Actions schedules `/api/cloud/worker` to continue unfinished batches.

The check validates behavior and no longer incorrectly requires GitHub Actions to call `/api/cron/daily`.
