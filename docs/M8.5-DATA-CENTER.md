# M8.6 Data Center

## Read path

Browser -> Next.js API -> Turso

No page route calls FinMind.

## Write/update path

User action -> update_queue -> server-side queue processor -> MarketPipeline -> FinMind -> Turso -> ai_snapshots

The queue de-duplicates `(symbol,purpose)`, retries temporary failures, and never deletes the last valid Turso result.
