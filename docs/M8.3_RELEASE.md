# twstock-M8.3 Release Notes

## 核心變更

市場風向只下載四項：

1. 費城半導體（SOX）
2. 台指夜盤代理
3. 美元／台幣（USD/TWD）
4. VIX 恐慌指數

## 評分原則

- SOX：電子與半導體環境。
- 台指夜盤代理：隔日台股方向。
- USD/TWD：台幣強弱與外資資金壓力，採反向計分。
- VIX：整體風險水位與變化。
- 市場風向只作風險調整，不取代個股價量、法人及技術面分析。

## 台指夜盤資料說明

免費 Yahoo 行情不保證固定提供台指夜盤代碼，因此依序嘗試：

```text
FITX → TXF=F → ^TWII
```

若前兩個期貨代碼不可用，系統會退回台灣加權指數作為代理，畫面名稱維持「台指夜盤代理」，避免誤認為交易所逐筆夜盤資料。
