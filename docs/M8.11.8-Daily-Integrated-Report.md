# M8.11.8 — Daily Integrated Intelligence Report & Fast5

## Goal
Replace multi-screenshot daily review with one dated report generated after the daily pipeline.

## Report contents
- TAIEX close / daily change / 5-day return / 20-day drawdown.
- Global proxies already used by Market Regime: SOX, Taiwan futures proxy, USD/TWD, VIX, including source quote dates.
- Early Watch EW-A / EW-B counts and Top5.
- Swing10 A1 / A0 and relative Top5.
- Fast5 research ranking for 5–10 trading-day readiness.
- Open Swing10 positions and hold/watch/sell-check counts.
- Plain-text summary and JSON export.

## Storage budget
One row per trading day in `daily_analysis_reports`. The row only stores the compact report JSON and text summary; it does not duplicate full market history.

## Fast5 policy
Fast5 is a research ranking only. It does not change A0/A1 grades, open positions, or auto-execute trades. It is designed to be validated against later 5–10 day outcomes before any future weight changes.
