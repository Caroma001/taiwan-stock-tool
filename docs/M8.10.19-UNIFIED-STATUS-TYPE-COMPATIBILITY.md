# M8.10.19 — Unified Status Type Compatibility

M8.10.18 unified the UI status source but its TypeScript contract omitted the
legacy `last_error` property still rendered by `GlobalUpdateProgress`.

M8.10.19:

- Adds `last_error?: string | null` to `UnifiedUpdateStatus`.
- Mirrors canonical error text into both `error` and `last_error`.
- Publishes `last_error` in the API `unifiedStatus` object.
- Versions the browser cache / leader / BroadcastChannel namespaces again.
- Adds a static compile-contract guard so this compatibility field cannot be
  removed while GlobalUpdateProgress still references it.
- Preserves all M8.10.18 Unified Status UI Binding behavior.
