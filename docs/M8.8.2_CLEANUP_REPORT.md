# M8.8.2 Cleanup Report

## Removed pages
AI engine/scanner, legacy analysis, cloud consoles, old dashboard, data quality, decision engine, indicators, offline page, legacy portfolio/watchlist, and duplicate foreign/Top30 pages. Old URLs are redirected in `next.config.ts`.

## Removed APIs
Legacy analysis-results, decisions, deployment, indicators, M7.2 dashboard/pipeline, monitoring, and validation APIs.

## Removed calculations
Daily AI validation snapshots and validation metrics are no longer refreshed by the one-click update or cloud scheduler. Existing Turso tables are not automatically dropped.

## UI fix
Display settings now opens as a right-side drawer below sticky bars, with viewport-safe top/bottom margins and mobile sizing.

## Package cleanup
Removed unused `axios` and `date-fns`. Release ZIP excludes `node_modules`, `.next`, `.vercel`, logs, and macOS metadata.
