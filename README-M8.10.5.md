# twstock M8.10.5 — Unified Stealth Radar

M8.10.5 將 Winner25 歷史模型與法人潛伏掃描整併成單一「潛伏雷達」工作頁。

## 每日流程

只需要按「一鍵更新潛伏雷達」：

1. 固定目前 40 檔候選。
2. 套用最近一次已通過 OOS Gate 的 Winner25 歷史規則。
3. 計算每檔即時 Breakout Score。
4. 計算外資潛伏、投信接棒、強勢回檔、籌碼集中與發動確認。
5. 產生法人潛伏分、潛伏階段與最終潛力分。
6. 重新讀取相同 40 檔 Live Score，立即更新排名。

## Winner25 歷史模型

完整兩年 Winner25 掃描不再放在主導覽的獨立頁面，也不會每日重跑。
潛伏雷達頁保留「重新訓練 Winner25 模型」按鈕，只有需要重新學習歷史規則時才執行。

舊網址 `/winner25` 會導向 `/stealth-scanner#history-model`，避免既有書籤失效。

## 頁面整合

潛伏雷達同頁顯示：

- Winner25 歷史樣本數、Winner 數、OOS Lift、模型狀態與最後訓練日期。
- 今日 40 檔候選的 Winner25 即時分與法人潛伏分。
- 外資潛伏、投信接棒、強勢回檔、籌碼集中、發動確認五構面。
- 可折疊的 Winner25 歷史規則與歷史強勢案例。

本版不修改 M8.10.4.4 已驗證的 Winner25 / 法人潛伏計分演算法，重點是整合工作流程與 UI。
