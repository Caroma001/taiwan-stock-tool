# twstock-M8.9.3 — Institutional Data Coverage Step 1

本版採逐步補強，不重抓既有兩年股價資料。

## 完成內容

- 每次更新外資資料時，同步保存投信與自營商每日買賣超。
- Bruce 精選的「投信 10 日」優先由 `institutional_holding_daily` 自動加總。
- 新增資料覆蓋卡片，清楚區分：
  - 外資買賣資料
  - 投信資料
  - 外資持股比例
  - 股權分散資料
- 新增「補齊前 20 檔法人資料」按鈕，避免一次大量呼叫 FinMind。
- 外資持股比例、大戶比例與散戶代理若沒有原始資料，仍顯示 `—`，不虛構數值。

## 本版暫不處理

- 外資持股比例歷史回補
- TDCC 股權分散週資料
- 大戶比例與散戶代理計算

上述項目預留於後續小版本逐步完成。
