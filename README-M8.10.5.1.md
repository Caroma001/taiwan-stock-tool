# twstock M8.10.6 — Stealth Radar Top20 Test Pool Reset

## 目標

M8.10.6 將舊規則建立的測試持股退出測試，改以「潛伏雷達」當下排名前 20 檔建立新的固定績效測試池。

### 安全邊界

- 不刪除實際持股。
- 不刪除既有交易歷史。
- 不刪除使用者手動建立的自選觀察。
- 舊測試持股改為 closed，不做假交易、不寫入正式交易紀錄。
- 舊 Bruce 自動觀察規則停用，避免測試池重新被舊策略污染。

## Top20 測試池

投資組合新增「重建潛伏雷達 Top20 測試池」。執行時：

1. 固定潛伏雷達 40 檔候選。
2. 依目前 Potential Score 排序。
3. 取前 20 檔有效收盤價股票。
4. 結束所有舊 test holdings。
5. 停用舊系統自動加入的 observation rows。
6. 以最新可用收盤價建立新的 20 檔 test holdings。

### 等權重

為避免 1 張高價股票對整體模擬資金影響遠高於低價股票，每檔以約 NT$100,000 名目資金建立模擬部位，允許零股：

- 20 檔總名目資金約 NT$2,000,000。
- 買進手續費依系統既有費率自動計算。
- 每檔保留固定 #01–#20 的選入排名，不會因後續漲跌重新編號。

## 績效

測試策略摘要新增：

- 資金加權報酬
- 等權平均報酬
- 勝率
- 獲利 / 未獲利檔數
- 10 / 20 交易日報酬

## 操作

先在 `/stealth-scanner` 執行「一鍵更新潛伏雷達」，再按「重建 Top20 測試池」。也可以在 `/portfolio-manager` 直接執行相同操作。
