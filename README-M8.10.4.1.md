# twstock M8.10.4.1 — Data Coverage Hotfix

本版修正 M8.10.4 法人潛伏掃描器的兩個資料整合問題：

1. Winner25 已完成且模型啟用，但法人潛伏頁仍顯示 0/40。
2. 潛伏分要求過多輔助資料齊全，導致大量股票顯示「資料不足」。

## 修正內容

- 更新法人潛伏分時，同步把即時計算的 Winner25 Breakout Score、模型狀態、Run ID 與理由寫回 `ai_analysis_latest`。
- 核心資料改為：價格趨勢/回檔特徵 + 外資 5/20 日相對成交量。
- 投信、外資持股變化、大戶/散戶變化改為輔助資料；缺少時動態重新分配有效構面的權重，不使用假值補齊。
- 潛伏資料可用門檻由固定 50% 改成核心資料完整且整體資料可信度至少 35%。
- 法人潛伏頁新增「完整度」與「資料缺口」欄位，讓缺資料原因直接可見。
- Winner25 欄位顯示模型是否為正式啟用模型（✓）或研究分數。

## 重要原則

- 不新增任何付費資料來源。
- 不以 0 代替缺失資料。
- Winner25 仍只使用訊號日前已知資料計算即時 Breakout Score。
- 缺少輔助籌碼資料不再整檔淘汰，但核心價格/外資資料不足時仍不產生正式法人潛伏分。
